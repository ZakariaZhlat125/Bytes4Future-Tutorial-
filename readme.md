# HTML Complete Course for Beginners
### From Zero to Building Real Web Pages

---

## Course Overview

This comprehensive HTML course is divided into two structured lessons, each designed to take you from beginner to intermediate level through a balanced mix of theory, practice, and review.

---

## Lesson 1: HTML Fundamentals

**Duration:** 3 hours per session
- 1 Hour: Theoretical Explanation + Live Coding
- 1.5 Hours: Practical Application (Student writes code)
- 0.5 Hours: Review, Questions, Problem Solving

**Topics Covered:**
- HTML basics, history, and importance
- HTML document structure and tags
- Head section (meta tags, SEO, Open Graph, favicon)
- Global attributes and data-* attributes
- Text formatting and headings
- Links and images (including responsive images with srcset)
- Lists (ordered, unordered, description)
- Block vs inline elements
- iframe embeds (YouTube, Google Maps)

**Practical Exercises:**
- Create your first HTML page
- Build an About Me page
- Create a links page
- Build an image gallery
- Design a resume page
- Implement SEO meta tags
- Use data attributes
- Create responsive images
- Embed iframes

**File:** [Lesson 1: HTML Fundamentals](Lesson1.md)

---

## Lesson 2: HTML Advanced Topics

**Duration:** 3 hours per session
- 1 Hour: Theoretical Explanation + Live Coding
- 1.5 Hours: Practical Application (Student writes code)
- 0.5 Hours: Review, Questions, Problem Solving

**Topics Covered:**
- Tables (structure, merging cells)
- Semantic elements (header, nav, main, footer, etc.)
- details and summary elements (collapsible content)
- Audio and video elements
- Forms (inputs, validation, various input types)
- Accessibility basics and ARIA
- HTML entities
- Live Server and Lighthouse
- HTML best practices

**Practical Exercises:**
- Create data tables
- Build semantic blog layouts
- Design contact forms
- Create media galleries
- Build registration forms
- Implement FAQ pages with details/summary
- Create accessible product pages

**File:** [Lesson 2: HTML Advanced Topics](Lesson2.md)

## Learning Approach

Each lesson follows a proven three-part structure:

1. **Theory + Live Coding** - Learn concepts with real-time demonstrations
2. **Hands-on Practice** - Apply knowledge through guided exercises
3. **Review + Problem Solving** - Reinforce learning and address challenges

---

## Prerequisites

- Text Editor (VS Code recommended)
- Modern Web Browser (Chrome, Firefox, or Edge)
- No prior programming experience required

---

## Course Completion

By the end of this course, you will be able to:
- Create structured, semantic HTML documents
- Build responsive, accessible websites
- Implement forms and user interactions
- Follow HTML best practices and standards
- Prepare for advanced CSS and JavaScript learning
